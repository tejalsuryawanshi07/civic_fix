## Product principles

- AI recommendations require human review before assignment.
- CivicFix initially manages complaints internally; it does not claim to submit them to government authorities.
- AI outputs are validated, logged, and treated as recommendations rather than authoritative decisions.
- User location and uploaded media are handled with privacy and access controls.

See the documentation above for the approved Phase 1 architecture and implementation plan.
